# Migration

1. **Rehost (lift & shift)**: Migrate existing applications to the cloud with minimal changes.
2. **Refactor (lift & optimize)**: Migrate applications to the cloud with some optimizations.
3. **Re-architect**: Rearchitect applications to fully leverage cloud-native services.
4. **Rebuild**: Rebuild applications from scratch using cloud-native services.
5. **Retire**: Retire applications that are no longer needed.
6. **Retain**: Keep applications in their current environment.

## DB
1. **Database Migration Service (DMS)**: Use online migration for minimal downtime.
2. **Schema Convertor**.
3. DB Migrate Assistant.

## Azure Migrate: Discovery
1. For on-premise HyperV & VMware. Explore on-premises servers to see what to move.

## WebApp
1. Webapp Migration Assistant.

## Migrate Assistance.
1. Requires a dedicated machine that is able to communicate with the source server and can access the Azure Migrate server.
2. Use Azure Migrate to assess your current infrastructure and make recommendations for the best way to move your applications to the cloud.
3. Use Azure Migrate: Server Migration to migrate VMs from on-premises to Azure.
